# Taskbar Media Widget (Windows)

Sleek glass now-playing card for Spotify / any media app.

## Setup (GitHub)
    git clone https://github.com/YOUR-USERNAME/taskbar-widget.git
    cd taskbar-widget
    setup.bat
    run.bat

## Change the look from the command line (updates live)
    .venv\Scripts\python widget.py theme neon
    .venv\Scripts\python widget.py set accent=#ff4fd8 radius=40 opacity=200
    .venv\Scripts\python widget.py set x=1400 y=800

Themes: midnight, neon, sunset, mono. You can also edit config.json by hand.

## Use
Drag to move, click the bar to seek, right-click for Quit.
